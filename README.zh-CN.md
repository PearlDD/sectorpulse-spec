# v0.4 — 美国宏观研究工作台（本地版）

打开 http://127.0.0.1:8000/。双击 `run-local.command` 可启动并打开页面；关闭启动窗口不停止服务，电脑重启后需重新启动。原 `run.sh` 仍用于首次安装。只监听本机，不部署云端。

## 本次新增

- 宏观工作台：13 条 FRED 公开序列，增长／通胀动量、就业和信用反证。页面显示观测期、抓取时间与可检查的规则。
- 新闻雷达：美联储、BLS、BEA 与 BBC World RSS，保存标题及出处，按主题筛选并对相同标题去重。未读取全文，传导路径为条件假设，新闻不自动参与周期评分。
- 日历：BLS、BEA 官方 ICS、美联储 FOMC 页面及联邦选举法定日期。处理美东夏令时；未知具体时刻不编造时间。
- 日更：服务启动时检查更新，美东 08:00／17:00 更新。失败来源每 30 分钟重试；失败保留旧资料但过期宏观资料不参与判断。电脑睡眠或关闭期间无法采集，补抓仅限来源仍保留的信息。
- 行业观察：住房、半导体、区域银行、工业运输、消费和能源的条件框架，列出确认／失效条件。缺少行业订单、库存、估值和盈利预期，**尚不确认任何行业筑底或买点**。
- SQLite 新增独立 `research_*` 表，每次有成功采集的更新保存研究与来源输入归档。原有价格报告、历史任务和快照保留在“价格辅助”。

## 来源与边界

FRED 公共 CSV 使用当前可见修订值，不是历史时点数据；月度比较按日历月份端点匹配，不按行号猜测。发布日期未获取时明确为空。周期阈值为未经概率校准的启发式规则，不能冒充 NBER 衰退认定。

本版没有接入市场一致预期、发布后实际／预期配对、ISM、国债拍卖或公司财报日历；不会标注“超预期”。没有启用自动付费 AI 调用，没有修改任何 Supabase 资源。规则没有通过前瞻收益验证。

新接口：`GET /api/research`、`POST /api/research/refresh`、`GET /api/research/reports`、`GET /api/research/reports/{id}`。自动采集可通过 `SECTORPULSE_RESEARCH_AUTO=0` 关闭（手动更新仍可用）。

# SectorPulse

[English / 完整 API 与部署说明](README.md) · [验证记录](VERIFICATION.md)

SectorPulse 是可在浏览器使用的板块研究工具，对比 11 只 SPDR 板块 ETF 与 SPY。保留 FastAPI、React、TypeScript、Vite、Tailwind、Recharts 架构。**仅用于教育和研究，不是投资建议、预测或收益保证。**

## 本地运行

需要 Python 3.12、Node.js 24 LTS、npm，以及 macOS/Linux。安装依赖和使用真实行情需要网络。在仓库目录运行：

```bash
bash run.sh
```

打开 **http://127.0.0.1:8000**。脚本创建虚拟环境、安装锁定依赖、构建前端，并由 FastAPI 同时提供页面和 API。以后启动可使用：

```bash
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

选择 Live providers 或 Synthetic demo、截止日期，然后点击 Refresh analysis。页面打开时只读取已保存记录，不自动请求行情或调用 AI。模拟数据始终明确标注，不会在真实行情失败后静默替换。

可选：复制 `.env.example` 为根目录 `.env`，配置 `FRED_API_KEY` / `ANTHROPIC_API_KEY` 并重启。所有密钥只放服务器端，不放入前端 `VITE_*` 变量，不提交 Git。没有 FRED 时仍能分析价格；没有 Anthropic 时仅禁用 AI 解释。

## v0.3 已完成

1. **可靠性**：SQLite 输入快照、SHA-256 指纹、报告历史、快照重算验证；后台刷新、去重、队列上限和明确的失败/超时/中断状态。失败不会覆盖上次成功报告。
2. **分析拆分**：相对强弱、绝对收益、波动、回撤和宏观证据分开显示。取消未经验证的固定周期加分，不强行给出经济周期标签。
3. **图表与验证**：板块/SPY 对比、自定义相对强弱轨迹图、时间留出验证及每期明细。轨迹图不是专有 JdK RRG 指标。
4. **可选 AI**：单独点击触发，只传白名单中的板块数值与覆盖信息，不传日期、原始历史或自由文本；解释单独保存，不能改变排名。

## 金融口径与边界

截止日期包含当天，默认纽约时间的昨天，不接受尚未结束的当天或未来日期。所有板块使用 SPY 最新 61 个观测交易日，不填补缺失行情；不足 80% 的合资格板块时不显示名次与领涨标签。

相对强弱分数 = 40% × 20 日相对 SPY 超额收益 + 60% × 60 日超额收益，单位是百分点。这些固定权重只是描述性规则，没有证据证明最优。相对领先仍可能绝对亏损。宏观和 AI 均不加分。

验证保留历史前 60%，只评估后 40%；每 21 个观测交易日选前三名，信号收盘后的下一收盘入场，持有 20 个交易日。篮子和 SPY 每期均扣除示意性的 20 bps 往返成本。未来缺数据就跳过整期，不利用未来信息换股。至少需要 504 个基准观测值和 6 个可用区间。

这是**回顾性的时间留出验证**，不是未经触碰的前瞻样本外实验，也不是完整可交易组合回测。真实行情测试得到 18 个区间、每期平均超额收益 **−0.0555 个百分点**，不能证明策略优势。没有为改善该结果调参。详见 [验证数据](eval/reports/validation-2025-12-31.json)。

FRED 使用截止日期的观测和 vintage 限制；Yahoo 复权历史仍可能被事后修订。快照保证可以复现本次输入，并不能证明当时可获取这些数据。没有接入完整交易所日历。去掉 AI 日期输入也不能保证模型完全没有历史知识或幻觉。

## 保存与任务

默认数据库：仓库根目录 `data/sectorpulse.db`，可用服务器环境变量 `SECTORPULSE_DB` 指定绝对路径。数据库与密钥不提交版本控制。偏好保存在本地浏览器。

只运行一个实例、一个 Uvicorn worker。最多四个待处理/运行任务，单个分析最长 15 分钟，AI 最长 90 秒。关闭浏览器后服务器继续工作；服务器重启将未完成任务标为 interrupted，用户明确重试。后台刷新不等于定时自动刷新。

备份时停止应用后复制数据库，或使用 SQLite 在线备份接口。没有自动清理历史，也没有迁移旧 PR 数据库。不要在多副本或临时文件系统上使用当前 SQLite 设计。

## 检查与部署

```bash
.venv/bin/python eval/score.py
```

运行后端测试、Ruff、mypy、前端严格类型检查、lint 和生产构建。开发时后端加 `--reload --port 8000`，前端运行 `npm run dev`，打开 http://127.0.0.1:5173。

部署配置已提供，但**没有部署到外部服务**：

```bash
docker compose up --build
```

容器通过同一来源提供前后端，`research-data` 卷保存数据库。不要用 `docker compose down -v` 删除需要保留的历史。托管时配置持久卷、单实例、服务端密钥、HTTPS 和访问受限的入口。当前无登录，任何能访问 API 的人都能查看共享历史、触发行情及 AI 请求，不宜直接公开。

前后端分开部署时，静态托管 `frontend/dist`，把 `/api/*` 反向代理到后端并保留前缀。刷新返回任务编号，浏览器轮询，不需要长时间阻塞请求。完整 API、存储和部署约束见英文 README。

当前限制：FRED 真实成功调用未验证；AI 真实调用在本环境失败，但模拟成功/失败及隔离逻辑已测试；没有认证、定时刷新、专业时点数据、成本校准或已证明的预测能力。Docker 构建运行是否经过验证见验证记录。
